# 使用指南

## 字体子集是什么

完整字体通常包含大量不会在项目中出现的字形。字体子集会保留你指定的文字、字符范围或预设字符，移除其余字形，从而减小文件体积。

例如，一份 16 MB 的中文字体若只需覆盖游戏内约 6,000 个字符，裁剪后通常会显著变小。具体缩小比例取决于字体本身、所选字符数量、字形复杂度和输出格式。

## 第一次使用

1. 在“选择字体”区域导入一份 TTF、OTF、WOFF 或 WOFF2 文件。
2. 在“需要保留的文字”中粘贴实际文案；也可以导入 UTF-8 TXT 文件。
3. 按需要选择字符预设，或在 Unicode 范围中输入例如 `U+4E00-U+9FFF`、`U+0020-U+007E`。
4. 选择输出格式。网页通常优先选 WOFF2；如需兼容较旧浏览器，再同时选择 WOFF。
5. 点击“生成字体子集”，查看输出大小和缺字提示，再下载字体或复制 `@font-face` CSS。

文本、Unicode 范围和预设会合并去重；空格始终会被保留。

## 怎样准备字符集

最稳妥的做法是直接收集项目中会显示的所有文本：静态文案、关卡配置、服务端下发文本、角色名、活动文案以及动态模板中的占位内容。预设适合做兜底，但不能替代真实文本。

### 内置预设

| 预设                        | 包含内容                                                           | 适用场景                               |
| --------------------------- | ------------------------------------------------------------------ | -------------------------------------- |
| ASCII 与常用标点            | `U+0020–U+007E`：空格、英文字母、数字和 ASCII 标点，共 95 个字符   | 英文、数字、技术符号                   |
| 中文标点与常用符号          | `U+2000–U+206F`、`U+20A0–U+20CF`、`U+3000–U+303F`、`U+FF01–U+FF65` | 全角标点、引号、书名号、货币和排版符号 |
| 简体中文常用字（3,500）     | 《通用规范汉字表（2013）》一级字表                                 | 文案量较小、用字比较常见的项目         |
| 简体中文通用字（6,500）     | 《通用规范汉字表（2013）》一、二级字表                             | 大多数简体中文游戏或网站的默认选择     |
| 简体中文完整规范字（8,105） | 《通用规范汉字表（2013）》全部三级字表                             | 需要覆盖姓名、地名和较多专门用字的项目 |

预设描述的是“请求保留的字符”，不保证每份字体都包含它们。缺少的字符会在结果页明确列出。

### Unicode 范围示例

```text
U+4E00-U+9FFF             # 一段常用汉字区
U+0020-U+007E             # ASCII 与英文标点
U+4E00-U+9FFF, U+3000-U+303F
U+4E00-U+4E02；U+0041     # 支持中文逗号、分号和换行分隔
```

单个范围和全部字符合计最多 120,000 个 code point。范围越大，生成结果通常越大。

## 怎样看结果

- **请求字符 / 实际可用**：前者是你要求保留的字符数，后者是源字体中真实存在的字符数。
- **缺失字符**：这些字符本来就不在源字体中，工具不会凭空生成字形，也不会把它们写入输出字体。
- **字形数量**：展示裁剪前后的字形数量。连字、替代字形和布局功能可能使字形数与字符数不同。
- **缩小比例**：仅用于快速判断效果；不同格式的压缩方式不同，不能跨格式直接比较。

看到缺字不代表裁剪失败。若项目运行时不会显示这些字，通常不影响使用；若会显示，请换用包含该字符的字体、补充字体或调整文案。

## 选择输出格式

| 格式  | 建议用途                              | 说明                                                       |
| ----- | ------------------------------------- | ---------------------------------------------------------- |
| WOFF2 | 现代网页，优先选择                    | 通常体积最小                                               |
| WOFF  | 兼容较旧网页环境                      | 可与 WOFF2 一起输出                                        |
| TTF   | Unity、桌面工具或需要 TrueType 的流程 | CFF/PostScript 轮廓字体不能无损导出为 TTF                  |
| OTF   | 保持 OpenType 文件形式                | TrueType 输入仍保留 TrueType 轮廓；CFF 输入仍保留 CFF 轮廓 |

当 CFF/PostScript OTF 输入时，TTF 选项会被禁用或忽略，以避免看似成功、实际改变轮廓的有损转换。

## 常见问题

### 字体会上传到服务器吗？

不会。解析、裁剪和压缩都在浏览器的 Worker 中完成。静态部署只负责提供页面和 WASM 文件。

### 为什么我选了 6,500 字，结果显示缺字？

字符预设来自标准字表，而字体的实际字符覆盖由字体本身决定。工具会保留字体中存在的部分，并列出不存在的字符。

### 为什么裁剪后没有想象中那么小？

字体表、布局信息、字形复杂度和保留的字符数量都会影响体积。请优先用真实文本裁剪，避免一次性选择过大的范围；也建议比较 WOFF2 和 WOFF 的结果。

### 工具会检查字体授权吗？

不会。请在导入、分发或上线子集前自行确认字体许可是否允许这些用途。
